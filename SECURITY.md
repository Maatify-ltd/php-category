# Security Policy

[![Maatify Category](https://img.shields.io/badge/Maatify-Category-blue?style=for-the-badge)](https://github.com/Maatify-ltd/php-category)
[![Maatify Ecosystem](https://img.shields.io/badge/Maatify-Ecosystem-9C27B0?style=for-the-badge)](https://github.com/Maatify-ltd)

## Scope

**Published release candidate:** [`v1.0.0-rc.1`](https://packagist.org/packages/maatify/php-category#v1.0.0-rc.1)

This policy covers package-owned runtime contracts, Composer metadata, schema,
and CI configuration. Host applications and their integrations remain outside
package support.

## Supported Versions

No Stable release line is currently supported. The Release Candidate does not
create a Stable support commitment.

| Version | Support status |
|---------|-----------------|
| `v1.0.0-rc.1` | Published Release Candidate; no Stable support commitment |
| Stable release lines | None |

## Reporting a Vulnerability

Please report vulnerabilities through the repository's
[private GitHub security advisory channel](https://github.com/Maatify-ltd/php-category/security/advisories/new).
Do not disclose sensitive details in a public issue.
